# My Python Backend

Backend API for my x10hosting frontend application.

## Local Development
```bash
# Create virtual environment
python -m venv venv

# Activate it
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Install dependencies
pip install -r requirements.txt

# Run locally
python app.py
